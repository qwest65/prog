# Telegram бот для майнера

Бот показывает полное состояние майнера одной кнопкой **«📊 Статус»**:
- хешрейт;
- температуру;
- ошибки.

Также есть авто-оповещение, если хешрейт упадет до `0`.

## Запуск

```bash
python bot.py
```

## Команды

- `/start` — показать меню с одной кнопкой;
- `/status` — показать полное состояние.

## Настройки

Переменные можно задавать через окружение (`.env.example`):
- `TELEGRAM_TOKEN`
- `MINER_BASE_URL`
- `POLL_INTERVAL_SECONDS`
- `REQUEST_TIMEOUT_SECONDS`
- `ALERT_COOLDOWN_MINUTES`
- `ALLOWED_CHAT_IDS`

По умолчанию уже установлен ваш токен и URL майнера.
